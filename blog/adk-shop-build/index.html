Shop Build

ADK Shop Build

ADK is a high-end custom fabrication shop with deep semi-truck parts experience. This shop build shows what that means in practice: suspension, stainless, lighting, fitment, and one-off details built around the truck.

After Dark KreationsJun 23, 20221 min read
All shop notesView shop workStart a custom build

The build standard

The original ADK shop build focused on a late-1970s Kenworth W900A undergoing a long-hood conversion. The truck served as a showcase for the shop’s skills, product ideas, and semi-truck fabrication language.

Truck details

The build was described with a 273-inch wheelbase, custom-fabricated front suspension, low air leaf rear suspension on new frame rails, 36-inch flat top ripple back sleeper, 5-inch chrome stacks, Hogebuilt quarter fenders, and 22.5-inch wheels.

Fabricated parts

ADK’s scope included a rear light bar, deck plate, toolbox, one-off stainless steel step boxes, and custom stainless fuel tank straps. That list says a lot about the shop: ADK is not only making decorative parts. It is building the pieces that define stance, service access, fitment, and final detail.

Powertrain and road use

The build notes included a C15 engine, 18-speed transmission, 2.97 gears, and 275/80R22.5 tires. That context matters because fabrication has to respect the truck’s use, load, packaging, and road behavior.

Customer-led fabrication

ADK’s original message was simple: the shop wants to hear what customers want so it can deliver. That remains the point. Air ride kits, light bars, bumpers, steps, tanks, light boxes, deck plates, tank straps, and one-off metalwork all start with the customer’s vision and become real through measurement, fabrication, and test fit.
