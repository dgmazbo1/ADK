# After Dark Kreations Website

Static website redesign for After Dark Kreations / ADK, a custom welding,
fabrication, truck parts, trailer repair, air ride, hydraulics, and metalworks
shop in Henderson, Nevada.

## Local Preview

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173/`.

## QA

```bash
npm run qa
node --check script.js
```

The QA script checks local anchors, external page links, stylesheets, and image
URLs.
